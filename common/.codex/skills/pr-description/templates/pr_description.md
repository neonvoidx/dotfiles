## PR Checklist

Please check if your PR fulfills the following requirements:

- [N] The commit message
- [N] Tests for the changes have been added (for bug fixes / features)
- [N] Docs have been added / updated (for bug fixes / features)

## Commit Message

In this format: `type: summary`

Types:
- `conf`: Changes to configuration files and scripts
- `docs`: Documentation only changes
- `feat`: A new feature
- `fix`: A bug fix
- `perf`: A code change that improves performance
- `refactor`: A code change that neither fixes a bug nor adds a feature
- `test`: Adding missing tests or correcting existing tests
